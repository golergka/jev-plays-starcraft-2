# Lab504: remove advisory diagnosis from repeated Bunker purchases

Lab467 introduced Jev-selected bottleneck context after an offline rebuild shift; lab472 tested sharing it with order-family questions, not removing it from purchases. This probe checks whether survival diagnosis drives repeated defensive construction in499.

Same first/middle/last Bunker-top states used in503 (5432,9836,12545), identical questions/options and full state except deleting jev_bottleneck_diagnosis. Alternating baseline/treatment order. Six calls cost $0.003795246, shared governor, no game orders.

All three pairs returned Bunker with and without diagnosis. These limited observations do not attribute the preference to advisory diagnosis and do not support another full run based solely on removing it. Earlier construction benefit and current unchanged decisions are context-specific; neither establishes universal value of the stage. No policy change deployed.
