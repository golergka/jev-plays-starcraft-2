that destination, then asks it to choose among the original execution modes.

select middle-east ordinary Move. The destination is unchanged; the mode now
omits combat along the route. This does not establish worse outcomes without
live execution, but provides no evidence that the decomposition fixes the
observed destination/attrition problem. Do not deploy it on this result.
